Source code. The files come from the official OpenConnect 9.21 Windows installer
(openconnect-installer-MinGW64-GnuTLS.exe), which OpenConnect's CI job "MinGW64/GnuTLS" builds:
    https://gitlab.com/openconnect/openconnect/-/blob/v9.21/.gitlab-ci.yml
    in the build image https://gitlab.com/openconnect/build-images
    with the installer script openconnect.nsi.in of https://gitlab.com/openconnect/openconnect/-/tree/v9.21
The libraries were built with Fedora's MinGW toolchain, as their version strings say; Fedora's MinGW
packages and their sources are at https://src.fedoraproject.org/rpms/mingw-<name>.
