# 시스템 원칙
- 자원 소유: 만든 쪽이 끝까지 정리
  - 사유: 정리 주체 불명 시 잔존 자원이 다음 세션 방해
- 수명 일치: 세션 종료 시 세션이 만든 것 전부 소멸
  - 사유: 남은 장치·주소·route가 통신 가로챔
- 역할 위임: 라이브러리 책임은 대행 금지, 실행 불가 시만 예외
  - 사유: 이중 처리 시 동작 충돌·책임 불명
- 사실 판정: 상태·원인은 관찰 사실로만 판정
  - 사유: 추정·대리 지표는 실제 상태와 어긋남
- 유한 대기: 모든 대기에 상한, 내부 상한 없으면 바깥에서 차단
  - 사유: 끝나지 않는 대기가 재연결 차단
- 무간섭 확인: 확인·감시는 사용자 통신에 영향 없음
  - 사유: 고속 연결이 제품 목표
- 손상 격리: 저장 데이터 일부 손상이 전체로 번지지 않음
  - 사유: 기록 초기화 시 멈춤·로그인 한도 상실
