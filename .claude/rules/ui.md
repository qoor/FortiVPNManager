# 원칙
- 설정의 위치와 순서는 모든 OS UI에서 동일
  - 설정이 속한 pane과 섹션
  - pane·섹션·항목의 순서
- 대상 OS 기본 형식 적용
  - 화면 모양
  - 컨트롤
- UI에서 판단 로직 금지
  - 버튼 활성 여부와 값의 유효성은 런타임이 보낸 값 그대로 사용
- 대상 OS에 없는 기능의 항목은 표시 금지
  - 예: Windows UI의 백그라운드 실행 승인 행

## macOS
- Apple HIG(Human Interface Guidelines) 준수

## Windows
- macOS 설정창 기준
- Fluent 디자인 가이드가 정한 부분은 Fluent 우선

# 저장 방식
- 입력 중 자동 저장 금지
  - 입력 도중의 값 저장 발생(예: 180 입력 중 18)

# 배치
- 섹션
  - 섹션마다 머리글
  - 설명은 섹션 아래 한두 문장
- 하위 항목(스위치에 딸린 항목, 펼친 항목)
  - 라벨만 들여쓰기
  - 입력 칸은 다른 행과 같은 열
- 접히는 항목
  - 펼친 항목의 구분선 있는 개별 행 표시
  - 이름에 안에 든 것과 성격을 함께 표기(예: "Realm (고급)", "IMAP 대체 수단 (선택)")
- 행 수에 맞춘 목록 높이
- 상태 문구 옆 버튼의 잘림 금지

## macOS
- 입력 칸 왼쪽 정렬

# 문구
- 사용자 승인 없는 문구 추가·수정 금지
- OS가 달라도 같은 뜻의 문장 사용
  - OS 이름(Keychain, Finder, 시스템 설정)만 대상 OS 이름으로 교체
- 사용자가 인지할 필요가 없는 내부 특성 및 부가 설명 금지
- 경고·안내
  - 문제 하나와 할 일 하나의 한두 문장 구성
  - 화면에 이미 보이는 내용 반복 금지
  - 위치 안내는 지금 화면 기준
  - 안내와 오류가 같은 말이면 하나만 표시
- 번호 값(포트 등)에 자릿수 구분 금지

# 설정 검색
- 대상: pane 이름, 설정 이름
- 설정값·로그 본문 검색 금지
- 언어: 앱 언어와 영어
- 영문 용어의 한글 표기(구글, 헬퍼) 검색어 추가 금지
- 모든 OS 구현의 macOS 한글 검색 측정 사례 통과 필요

# 아이콘
- 최신 macOS 기본 앱과 유사한 스타일 기준
- 빨간색 금지
  - Fortinet·FortiClient로 오해되는 것 방지

# 결과 확인
- UI 변경 결과의 글 전용 보고 금지
- 사용자에게 화면 캡처 제공
- 실환경 기준 언어별 자동 검증 수행
