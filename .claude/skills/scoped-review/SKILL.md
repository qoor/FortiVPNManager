# 리뷰 범위
- 브랜치 전체 diff 리뷰 금지
- 대상
  - 이번 변경 파일
  - 변경이 직접 영향을 주는 호출하는 쪽·호출되는 쪽 코드

# 리뷰 실행
- 리뷰 목적 판단
  - 기준: 사용자 요청
  - 애매하면 질문
- 내장 code-review skill에 리뷰 범위의 파일을 대상으로 지정해 실행
- 리뷰어 전달 사항
  - 범위 밖 기존 동작·코드 수정 권고 금지
  - 명확한 근거가 없는 추정 사항에 대한 개선 제안 금지
  - 공통 지적 대상과 해당 목적의 지적 대상
- 리뷰 요청에 작성자 판단(설계 타당성 근거·결론) 제외

# 공통 지적 대상
- CLAUDE.md "코드" 규칙 위반
- 시스템 원칙 위반(구조 변경으로 위반이 된 기존 코드 포함)
- 승인 범위 밖 동작·UI 변경
- 목적과 무관한 변경 혼합
- 바뀐 동작의 SPEC 반영 누락
- 확인되지 않은 케이스 및 추정에 의한 불필요한 방어 코드
- 목적이 불분명하거나 효과가 미약한 추상화

## 버그
