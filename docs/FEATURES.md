# 시스템 영역 (Helper 서비스)
## 목적
- 시스템 레벨에서 실제 VPN 연결을 위한 인증, 터널 관리를 통해 VPN 구간 통신 지원
## 메인 서비스
- VPN Helper 서비스
## 기능
### 1. VPN 연결 관리
- VPN 멀티 세션 관리 기능
- VPN 세션 연결 관리 기능

### 2. 앱 연동 관리
- 앱 요청 채널 관리 기능
- Helper 전파 채널 관리 기능
- Helper 로그 채널 관리 기능
- 앱 요청 분석 기능

### 3. 네트워크 관리
- VPN 터널 설정 기능
- 예외 경로 관리 기능
- 네트워크 상태 관리 기능

### 4. Helper 운영 상태 관리
- 운영 상태 확인 기능
- 운영 상태 저장 기능

### 5. 로그 관리
- VPN 로그 기록 기능
- Helper 로그 기록 기능
- 시스템 로그 기록 기능

### 6. 업데이트 관리
- 업데이트 준비 기능
- 업데이트 설치 기능
