# 설정 UI 결정

macOS 설정창은 실제 macOS 컨트롤로 만든 목업을 macOS 27 시스템 설정과 비교해 보며 정했다(2026-11-12 ~ 11-13). 이 문서는 그때의 결정 가운데 **다른 OS의 UI(Windows의 WinUI 3, 이후 Linux)도 따를 것**을 모은다.

- 왜 그렇게 정했는지는 [DESIGN.md](DESIGN.md) §5.6과 결정 이력, 무엇을 하는지는 [SPEC.md](SPEC.md)가 기준이다.
- 화면 구성의 기준은 `components/ui/macos/*Pane.swift`, 문구와 번역의 기준은 `components/ui/macos/Localizable.xcstrings`(원문 영어, 한국어 번역)다.
- "사용자 결정"이라고 적은 것은 사용자가 직접 정했다. 나머지는 HIG 검토나 시스템 설정 측정으로 정해 사용자가 승인했다.

## 1. 원칙

- 같게 할 것은 설정이 **어느 pane과 묶음에 속하는지와 그 순서**다. 화면 모양과 컨트롤은 그 OS의 기본을 따른다(사용자 설명, 2026-11-12).
- pane은 창 왼쪽의 사이드바로 고른다. 다른 OS도 위쪽 탭이나 pane 버튼으로 되돌리지 않는다(사용자 결정, 2026-11-12).
- UI는 판단하지 않는다. 버튼을 켤지, 값이 맞는지는 런타임이 보낸 구역 값을 그대로 쓴다.
- 그 OS에 없는 항목은 뺀다. Windows에는 openfortivpn 설정 가져오기와 Helper 승인이 없다.

## 2. 창과 탐색

사이드바 맨 위에 설정 검색이 있고, 그 아래 pane 목록이 있다.

| 순서 | 한국어 | English | macOS 아이콘 (SF Symbol) | 내용 |
|---|---|---|---|---|
| 1 | 일반 | General | gearshape | 연결 상태와 버튼, 시작 옵션, 설정 가져오기 |
| 2 | 계정 | Account | person.crop.circle | VPN 계정, 2단계 인증(Gmail) |
| 3 | 연결 관리 | Connection | network | 스케줄, 재연결 |
| 4 | 예외 규칙 | Exception Rules | arrow.triangle.branch | 현재 네트워크, 두 목록, 적용 상태 |
| 5 | 고급 | Advanced | wrench.and.screwdriver | Helper, VPN client, 설정 파일 |
| 6 | 로그 | Log | doc.plaintext | 로그 보기와 찾기 |

- 창 제목은 지금 pane의 이름이다.
- 다시 열면 마지막으로 본 pane이 열린다.
- **뒤로·앞으로**
  - 본 pane을 차례로 되짚는다. 새 pane을 고르면 앞으로 이력은 지운다. 이력이 없으면 흐리게 한다.
  - 버튼은 모든 pane에서 같은 자리에 늘 둔다. pane마다 도구 영역이 생겼다 없어지면 창 위쪽 높이와 본문 시작 위치가 흔들렸다.
- **pane의 동작**
  - 저장, 적용, 로그 찾기 같은 pane의 동작은 창 위쪽 도구 영역의 오른쪽에 둔다. 창 아래쪽 막대에는 두지 않는다.
  - 같은 동작을 키보드로도 할 수 있게 한다. macOS는 메뉴 막대와 단축키로 둔다(저장·적용 ⌘S, 뒤로 ⌘[, 앞으로 ⌘], 설정 검색 ⌘⌥F, 로그 지우기 ⌘K). 다른 OS는 그 OS의 관례를 따른다(예: Windows의 Ctrl+S, Alt+←).
- **창 크기와 위치**: macOS는 시스템 설정과 같게 했다(사용자 결정, 2026-11-12). 다른 OS는 그 OS의 설정 앱을 기준으로 정한다.

## 3. 저장 방식

pane마다 저장 시점이 다르다. 모두를 하나의 저장 버튼으로 묶지 않는다.

- **일반·연결 관리**: 바꾸는 즉시 저장한다.
  - 숫자 칸은 Enter를 누르거나 포커스를 잃을 때 저장한다. 글자마다 저장하면 180을 치는 도중의 18 같은 값이 저장된다.
- **계정**: 입력은 초안이고 도구 영역의 [되돌리기] [저장]으로 확정한다. [저장]이 기본 버튼이다.
  - 연결 방식과 Google 계정 버튼은 저장을 기다리지 않고 바로 동작한다.
- **예외 규칙**: 두 목록은 초안이고 [변경 취소] [적용]으로 확정한다.
  - 고쳐야 할 주소가 있으면 적용할 수 없다.
  - 행을 입력하는 중에도 [적용]과 [변경 취소]를 누를 수 있다. 누르면 그 행의 입력을 먼저 확정한다.
- **입력 중 이동**: pane을 옮기면(뒤로·앞으로 포함) 입력 중인 값을 포커스를 잃을 때처럼 확정한다.
- **결과 표시**
  - 저장·적용 뒤 결과만 알리는 확인창은 띄우지 않는다. 결과는 버튼 상태, 상태 행, "저장했습니다."처럼 제자리에 보인다.
  - 연결 중에 계정을 저장하면 "저장한 계정 설정은 다음 연결부터 적용됩니다."를 두 곳에 둔다. 일반의 현재 상태 아래와 계정의 VPN 묶음 아래다.

## 4. pane 구성

묶음(섹션) 이름은 굵게 적고, 묶음 안의 항목을 위에서 아래 순서로 적는다.

### 일반

- **상태**
  - 현재 상태는 아이콘과 색으로 구분한다: 연결됨은 초록 체크, 끊김은 회색, 연결·재연결 중은 회색 화살표, 오류는 주황 경고다. 그 아래에 "다음 연결부터 적용" 안내를 둔다.
  - 사유는 기다리는 동안 그 이유를 보인다.
  - 설정이 필요하면 빠진 항목마다 버튼을 하나씩 둔다. 실패하면 안내 한 줄과 도움이 되는 pane을 여는 버튼을 둔다.
  - 연결된 동안에는 연결 시각, 터널 IP(선택해서 복사 가능), 다음 사전 재연결을 보인다.
  - 다음 시도를 보인다.
  - [연결] [연결 해제] [지금 재연결]은 늘 보이고, 지금 쓸 수 없으면 흐리게 한다.
- **시작 옵션**: 로그인 시 열기(스위치), 앱 시작 시 자동 연결(스위치). 필요할 때만 각 항목 아래에 안내 한 줄을 둔다.
- **설정 가져오기**(macOS만)
  - "openfortivpn 설정" 행에 설명과 [가져오기…]를 두고, 그 아래에 가져오기 결과를 보인다.
  - 계정에서 일반으로 옮겼다(사용자 결정, 2026-11-12).

### 계정

- 맨 위에는 있을 때만 저장 결과와 저장된 계정의 문제를 보인다.
- **VPN**: 서버 주소, 포트, 사용자 이름, 비밀번호, 접힌 "Realm (고급)" 안의 Realm 순이다.
  - 포트 칸은 숫자 길이에 맞게 좁게 둔다.
  - 비밀번호 칸이 비어 있을 때의 안내 문구: 저장된 비밀번호가 있으면 "Keychain에 저장됨 · 변경할 때만 입력", 없으면 "입력 필요".
  - 묶음 아래에 "다음 연결부터 적용" 안내를 둔다.
- **2단계 인증 (Gmail)**: Gmail 주소, 연결 방식(Google 계정 (Gmail API) / 앱 비밀번호 (IMAP)) 다음에 방식별 항목을 둔다.
  - **Google 계정 방식**
    - Google 계정 행: 상태와 [취소] / [연결 해제] / [Google 계정 연결…]
    - 접힌 "IMAP 대체 수단 (선택)": 앱 비밀번호와 그 설명
    - 접힌 "OAuth 클라이언트 (고급)": OAuth 클라이언트 행, [내장 클라이언트 사용] [JSON 가져오기…]. 내장 클라이언트가 없는 빌드에서는 펼친 채로 연다.
  - **앱 비밀번호 방식**: 앱 비밀번호.
  - 그다음 [Gmail 연결 테스트]와 그 결과.
  - 묶음 아래에 방식별 안내 한 줄과 Gmail 필터 권장을 둔다.
- Google 연결 해제 확인창의 [연결 해제]는 파괴적 스타일로 칠하지 않는다. 사용자가 직접 고른 동작이기 때문이다.

### 연결 관리

- **스케줄**
  - "스케줄에 따라 연결" 스위치 아래에 하위 항목을 들여 둔다: 요일(토글 버튼 7개), 시작 시각, 종료 시각, 자리 비운 후 재연결 중단(분), 다음 동작.
  - 스케줄이 꺼져 있으면 하위 항목을 흐리게 한다.
  - 묶음 아래에 설명을 둔다.
- **재연결**
  - 세션 최대 시간(분)
  - 사전 재연결(스위치)과 그 하위의 여유 시간(분)
  - 잠자기 후 재연결(스위치)과 그 하위의 최소 잠자기 시간(분)
  - 묶음 아래 설명: "서버가 세션을 끊기 전(세션 최대 시간 − 여유 시간)에 미리 다시 연결합니다."
- **분 단위 칸**: 숫자 칸, "분", 스테퍼로 이뤄진다. 스테퍼는 범위 끝에서 멈춘다. macOS에서는 Shift-클릭하면 10분씩 바뀐다.

### 예외 규칙

- **현재 네트워크**
  - "Wi-Fi · 192.168.0.12"처럼 서비스 이름과 주소만 보이고, 선택해서 복사할 수 있다.
  - 규칙을 적용할 네트워크 안인지 밖인지는 적지 않는다. 상태 행이 알려 준다(사용자 결정, 2026-11-13).
- **규칙을 적용할 네트워크**: [현재 네트워크 추가], 목록, + / −.
- **예외 대상**: 목록, + / −. 묶음 아래에 설명 한 줄을 두고, 자세한 설명은 help tag에 둔다.
- **상태**: 다음 순서로 하나를 보인다.
  1. 고칠 주소가 있으면 "표시한 주소를 고쳐야 적용할 수 있습니다."
  2. 적용하지 않은 변경이 있으면 "적용하지 않은 변경 사항이 있습니다."
  3. 그 밖에는 런타임이 보낸 상태.

  적용 실패와 재시도 중단은 따로 한 줄씩 보인다.
- **두 목록**
  - 두 목록은 별도 묶음으로 나눈다. 한 묶음에 두면 서로 붙어 보였다.
  - 행에는 주소만 보인다. 열 머리글과 행 라벨은 없다.
  - 빈 목록 안내는 두 목록이 같은 형식이다(사용자 결정, 2026-11-13).
    - 네트워크: "여기를 더블클릭하거나 +를 눌러 네트워크를 추가하세요."
    - 예외 대상: "여기를 더블클릭하거나 +를 눌러 호스트나 네트워크를 추가하세요."
    - 예시 주소는 안내에 넣지 않고, 새 행의 빈 칸 안내(예: 10.20.161.0/24)에 둔다.
  - 문제가 있는 행에는 빨간 표시를 한다.
  - 런타임은 첫 문제 하나만 설명한다. 그 행 옆에만 짧은 설명(예: "Overlaps 10.0.0.0/8.")을 두고, 전체 설명은 help tag에 둔다. 첫 문제는 네트워크 목록에 문제가 있으면 네트워크 목록에, 없으면 예외 대상 목록에 있다(사용자 결정: 이번에는 UI만 바꾼다, 2026-11-12).

### 고급

- **Helper**
  - 상태, [Helper 등록], 등록 오류.
  - 백그라운드 실행 승인 행(macOS만): 승인할 위치와 [시스템 설정 열기…]를 둔다. 승인이 필요하면 위치 안내가 할 일 안내로 바뀌고, 따로 한 줄을 더 두지 않는다.
- **VPN client**: 경로(선택 가능, 길면 가운데 생략), 버전, 검증되지 않은 버전 경고와 문제.
- **설정 파일**: 경로와 [Finder에서 보기], 아직 없을 때 안내, 읽기 오류와 경고.

### 로그

- 자동 스크롤 체크박스 아래에 로그 본문이 있다. 본문은 다른 묶음과 같은 둥근 배경 상자 안에 둔다.
- 도구 영역에 찾기, 지우기, 모두 복사, Finder에서 보기를 둔다.
  - 지우기는 화면만 지우고 로그 파일은 둔다.
  - 아이콘만 있는 버튼에는 모두 tooltip을 단다.
- 다른 pane에 다녀와도 보던 위치와 찾기 막대가 그대로다.
- 찾기 막대에서 다음·이전 찾기를 해도 키보드는 찾기 입력란에 남는다.

## 5. 설정 검색

- **대상**: pane 이름과 설정 이름이다. 설정값과 로그 본문은 찾지 않는다.
- **언어**: 앱 언어와 영어 둘 다로 찾는다(사용자 결정, 2026-11-12). 영문 용어의 한글 표기(구글, 헬퍼)는 넣지 않는다. 시스템 설정도 "블루투스"로는 Bluetooth를 찾지 못한다.
- 공백으로 나눈 단어가 모두 맞아야 한다.
- **결과**
  - 일치한 pane만 남고, 그 아래에 일치한 설정이 각각 고를 수 있는 행으로 나온다.
  - pane 이름이 맞으면 그 pane이 결과이므로 하위 설정은 나열하지 않는다.
  - 지금 화면에 없는 설정은 결과에서 뺀다. 예를 들어 IMAP 방식일 때의 OAuth 항목, 연결되지 않았을 때의 터널 IP다.
  - 긴 이름은 세 줄까지 줄바꿈한다. 일치하는 것이 없으면 "검색 결과 없음"을 보인다.
- **결과를 고르면** 그 pane으로 가서 접힌 묶음을 펼치고, 그 행으로 스크롤해 2초쯤 강조한다.
  - 여러 설정이 한 행을 같이 쓰면(연결·연결 해제·지금 재연결) 그 행으로 간다.
  - 도구 영역의 동작(로그의 찾기 등)은 강조할 행이 없으므로 pane으로만 간다.
- **키보드**
  - 검색어를 입력하기만 해서는 오른쪽 화면이 바뀌지 않는다.
  - ↓는 첫 결과를 고르고 키보드를 결과 목록으로 옮긴다.
  - Enter는 첫 결과로 가고, 키보드는 검색란에 남는다.
  - 검색 단축키(macOS ⌘⌥F)는 어느 pane에서든 검색란으로 간다.
  - 찾기(⌘F)는 로그 pane에서는 로그 찾기, 다른 pane에서는 설정 검색이다.
- **한글**: macOS 27 시스템 설정을 측정해 같은 규칙으로 맞췄다(사용자 요청, 2026-11-12).
  - 입력기가 조합 중인 글자도 검색어에 넣는다.
  - 마지막 글자를 뺀 앞부분은 음절 그대로, 이름 어디서든 맞아야 한다(터ㄹ → 배터리).
  - 마지막 글자만 자모 단위로 맞춘다. 홀로 친 자음은 그 자음으로 시작하는 음절과 맞고(배ㅌ, ㄷ), 음절은 그 음절로 시작하는 음절과 맞는다(디스프 → 디스플레이).
  - 한 글자 검색어의 받침은 다음 음절의 첫소리로도 본다. 단, 단어 첫머리에서만이다(뱉 → 배터리, 렝 → 레이아웃은 맞고, 털 → 배터리는 맞지 않는다).
  - 앞 글자의 자모(ㄷ스플레이), 초성 약어(ㅂㅌㄹ), 모음이 다른 경우(배텨)는 맞지 않는다.
  - 영문은 대소문자를 가리지 않는다.
  - 측정 사례 26개가 `components/ui/tests/macos/SettingsSearchTests.swift`에 있다. 다른 OS의 구현도 같은 사례를 통과해야 한다.

## 6. 배치

- 묶음마다 머리글을 둔다. 설명은 묶음 아래에 한두 문장으로 두고, 자세한 설명은 help tag에 둔다.
- 하위 항목(스위치에 딸린 항목, 펼친 항목)은 라벨만 들여 쓰고, 입력 칸은 다른 행과 같은 열에 둔다.
- **접힌 묶음**
  - 펼치면 안의 항목을 구분선이 있는 각자의 행으로 그린다. 묶음 안에 행·설명·버튼을 그대로 넣었을 때는 서로 붙고 가운데 정렬됐다(사용자 피드백, 2026-11-12).
  - 묶음 이름에는 안에 든 것과 그 성격을 함께 적는다: "Realm (고급)", "IMAP 대체 수단 (선택)", "OAuth 클라이언트 (고급)".
- 입력 칸은 모두 왼쪽 정렬이다.
- 행 설명은 라벨 아래에 둔다. 라벨 열을 넓힐 만큼 긴 설명은 행 아래 전체 폭에 둔다.
- 버튼은 행의 오른쪽 끝에 둔다.
- 복사할 만한 값(터널 IP, 현재 네트워크, 경로)은 선택할 수 있게 하고, 긴 경로는 가운데를 생략한다.
- 도움말 버튼은 두지 않는다. 사용자용 도움말 문서가 없다(사용자 결정, 2026-11-12).

## 7. 문구

- 다른 OS도 같은 뜻의 문장을 쓴다. Windows는 OS 이름이 들어간 곳(Keychain, Finder, 시스템 설정)을 그 OS의 이름으로 바꾼다.
- **용어**(사용자 결정)
  - "세션 최대 시간"이라고 쓴다. "최대 세션 길이"는 "길이"가 어색하다고 했다(2026-11-12).
  - "네트워크"라고 쓴다. "대역"은 쓰지 않는다(규칙을 적용할 네트워크, 현재 네트워크 추가).
  - "사용자 이름"이라고 쓴다. "사용자명"은 쓰지 않는다.
- **경고와 안내는 짧게**: 문제 하나와 할 일 하나를 한두 문장으로 쓴다(사용자 결정, 2026-11-13).
  - 화면에 이미 보이는 것은 되풀이하지 않는다. 예를 들어 포트 칸이 바로 아래 있으니 "포트는 포트 칸에 입력합니다"는 쓰지 않는다. openfortivpn 행 아래 문구에는 openfortivpn을 다시 쓰지 않는다.
  - 위치 안내는 지금 화면을 기준으로 쓴다. 가져오기를 일반으로 옮긴 뒤로는 "위에서 입력하세요"가 아니라 "계정에서 입력하세요"다.
  - 진행 중 표시는 짧게 쓴다: "브라우저에서 로그인 중…".
  - 같은 내용을 두 번 보이지 않는다. 안내와 오류가 같은 말이면 하나만 둔다.
- 포트처럼 번호인 값은 자릿수 구분 없이 쓴다(10443이고, 10,443이 아니다).
- 더 입력을 받는 동작의 버튼 이름은 "…"로 끝낸다(가져오기…, Google 계정 연결…, 시스템 설정 열기…).

## 8. macOS에서만 정한 값

다른 OS는 아래 값을 따르지 않고 그 OS의 설정 앱을 기준으로 정한다.

- **창**
  - 크기는 740×625pt로 고정이다. macOS 27 시스템 설정을 잰 값이다.
  - 처음에는 화면 정가운데에, 그 뒤로는 마지막 위치에 열린다. 그 위치가 화면을 벗어나면 화면 안으로 옮긴다.
  - 전체 화면은 없고, 최소화는 할 수 있다.
- **사이드바와 검색란**: 사이드바 폭은 220pt다(시스템 설정은 232pt인데 사용자가 더 좁게 정했다). 검색란 높이는 28pt다.
- **메뉴 막대**
  - 창이 열려 있는 동안 앱은 Dock 아이콘과 표준 메뉴(앱, 파일, 편집, 보기, 윈도우)를 가진다.
  - 도구막대의 동작은 모두 메뉴에도 있다(HIG Toolbars). 파일 메뉴의 저장·되돌리기는 pane에 따라 적용·변경 취소로 이름이 바뀐다.
